## 需求背景

用户希望在本项目内**本地复刻** Bilibili 第五人格 Wiki（`wiki.biligame.com/dwrg`），核心需求：
- 采用 **Vue 3 + Vite** 技术栈。
- 所有数据通过 **本地 mock JSON** 维护，不依赖后端 API。
- 核心模块为**角色图鉴（求生者 + 监管者）**。
- 后续补充强调：**以剧情为主**，包含角色剧情（推演、生日信）和活动剧情等。

## 技术选型

| 项目 | 选择 | 原因 |
|------|------|------|
| 框架 | Vue 3 + Vite | 用户指定，轻量高效 |
| 路由 | vue-router@4 | 单页应用必备 |
| 样式 | 原生 CSS | 不引入重型 UI 框架，保持项目简洁 |
| 数据 | 本地 JSON | 零后端，直接编辑即可扩展 |

## 环境约束与应对

**问题**：当前开发环境（bash on Windows）中 `npm` 不可用，无法运行 `npm create vite` 初始化项目。

**解决方案**：直接手动创建完整的 Vite + Vue 3 项目文件结构，包括 `package.json`、`vite.config.js`、所有源码文件。用户可在本地有 Node 的环境中运行 `npm install && npm run dev`。

## 文件创建清单

### 配置层
- `package.json` — 依赖：vue、vue-router；开发依赖：vite、@vitejs/plugin-vue
- `vite.config.js` — 标准 Vue 插件配置
- `index.html` — 入口 HTML
- `.gitignore` — 排除 node_modules、dist、.idea、.claude

### 源码层
- `src/main.js` — 创建 Vue 应用，挂载路由和全局样式
- `src/router/index.js` — 定义四个路由：首页、角色列表、角色详情、剧情收录
- `src/assets/style.css` — 全局 CSS 变量（暗黑哥特风格配色）

### 数据层
- `src/data/characters.json` — 6 名示例角色（3 求生者 + 3 监管者），包含：
  - 基础信息（名称、阵营、定位、难度、上线日期）
  - 技能列表（外在特质）
  - 推荐天赋、标签
  - **角色剧情节点**（推演、生日信）
- `src/data/stories.json` — 4 条示例活动/主线剧情

### 组件层
- `src/components/NavHeader.vue` — 顶部导航（首页 / 角色图鉴 / 剧情收录）
- `src/components/CharacterCard.vue` — 角色卡片（头像 + 名称 + 阵营标签）

### 页面层
- `src/views/HomeView.vue` — Wiki 风格首页，两个快速入口卡片
- `src/views/CharacterListView.vue` — 角色图鉴，顶部 Tab 切换全部/求生者/监管者
- `src/views/CharacterDetailView.vue` — 角色详情，四个标签页：
  1. **背景与剧情**（背景故事 + 角色剧情节点）
  2. 技能
  3. 天赋
  4. 标签
- `src/views/StoryListView.vue` — 剧情收录页，展示活动剧情列表 + 有剧情的角色快捷入口

## 设计决策

1. **配色方案**：采用深棕（`#1a1510`）+ 暗金（`#c9a227`）+ 米白（`#e8dcc8`），契合第五人格的哥特风格。
2. **响应式布局**：角色列表和剧情卡片使用 CSS Grid 的 `auto-fill` + `minmax`，适配不同屏幕宽度。
3. **剧情数据内聚**：角色剧情直接嵌入 `characters.json` 的 `stories` 数组中，避免跨文件关联，方便后续用户自行维护。
4. **路由参数传递**：角色详情页通过 `props: true` 接收 `:id`，在组件内用 `computed` 从 JSON 中查找对应角色，实现零后端的数据绑定。

## 可扩展方向

- 替换 `avatar` 字段为本地 `public/avatars/` 下的真实图片资源。
- 在 `StoryListView` 中增加活动剧情的详情页路由（`/stories/:id`）。
- 新增 `maps.json`、`items.json` 等数据文件，扩展地图攻略、道具资料模块。
- 引入 Markdown 渲染，支持更丰富的剧情文本格式。

## 验证步骤

1. 在项目根目录执行 `npm install`。
2. 执行 `npm run dev`，访问 `http://localhost:5173/`。
3. 确认首页显示正常，导航可跳转。
4. 进入「角色图鉴」，Tab 切换过滤正确。
5. 点击角色卡片进入详情，「背景与剧情」标签展示角色故事。
6. 进入「剧情收录」，活动剧情和角色剧情入口均正常显示。
