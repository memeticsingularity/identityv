## 设计目标

- **剧情与资料分离**：把剧情相关（背景、推演、信件）和角色资料/玩法相关（档案、技能、天赋、标签）在 Tab 层级彻底分开。
- **减少 Tab 数量**：技能、天赋、标签内容量较少，不需要单独占 Tab，统一收进「角色档案」。
- **可扩展性**：时装、随身物品数据量大且会持续新增，保留独立 Tab 并支持筛选/排序。

---

## Tab 划分

| Tab 名称 | 内容 | 显示条件 |
|----------|------|----------|
| **角色档案** | 角色档案（生日/年龄/菜品/VAs 等）、关系网、外在特质/技能、推荐天赋、角色标签 | 只要存在 profile / abilities / talents / tags 中任意一个 |
| **背景与剧情** | 背景故事、推演（左栏）、信件与档案（右栏） | 始终显示（已有 background/stories 兜底） |
| **时装** | 时装表格：名称、品质、获取方式、价格、描述、备注 | `skins.length > 0` |
| **随身物品** | 随身物品表格：同上字段 | `accessories.length > 0` |
| **关联分析** | 关联的剧情分析文章列表 | 始终显示 |

## 折叠面板（CollapsiblePanel）规范

### 背景与剧情页
- **推演** 和 **信件与档案** 分左右两栏。
- 每个节点使用 `CollapsiblePanel`。
- **默认状态**：展开（`default-expanded="true"`）。
- 传闻节点放在左侧推演栏。

### 角色档案页
- **角色档案网格**（`profile-grid`）中统一展示：生日、年龄、擅长、喜欢、厌恶、特质、菜品、配音、推荐天赋、角色标签等。推荐天赋和角色标签以文本形式直接展示在网格中，与年龄、生日等字段平级。
- **每个外在特质 / 技能** 独立使用 `CollapsiblePanel`，标题为技能名称。
- **默认状态**：展开（`default-expanded="true"`）。

## 表格交互规范（时装 / 随身物品）

### 筛选
- 顶部提供 **品质筛选 chips**。
- chips 动态生成（从当前数据中读取存在的 `rarity` 去重）。
- 最后一个 chip 为「全部」，用于重置筛选。
- 点击已选中的 chip 再次取消筛选。

### 排序
- 表头支持点击排序的列：**名称、品质、获取方式、价格**。
- 点击一次升序（▲），再次点击降序（▼），第三次取消排序。
- 排序仅对当前已筛选结果生效。

### 响应式
- 小屏幕（<= 900px）表格区域出现横向滚动条，禁止内容被挤压换行导致不可读。

### 品质颜色映射

| 品质 | CSS 类 | 背景 / 文字色 |
|------|--------|---------------|
| 虚妄杰作 | `rarity-splus` | 暗紫 / 浅粉 |
| 稀世 | `rarity-s` | 暗金 / 米黄 |
| 奇珍 | `rarity-a` | 深蓝 / 浅蓝 |
| 独特 | `rarity-b` | 深紫 / 浅紫 |
| 罕见 | `rarity-c` | 深绿 / 浅绿 |
| 其他 | `rarity-default` | 深灰 / 浅灰 |

## 数据结构约定

- 每个角色目录下固定六个 JSON 文件：
  - `profile.json`
  - `gameplay.json`
  - `abilities.json`
  - `stories.json`
  - `skins.json`
  - `accessories.json`
- `skins.json` 与 `accessories.json` 为对象数组，字段统一为：`name`, `rarity`, `obtain`, `price`, `description`, `note`。
