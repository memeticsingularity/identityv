# 项目文档

本目录用于存放与项目相关的开发记录、排错笔记、设计方案等非代码文档。

## 编号规则

所有文档采用 `XXX-YYYYMMDD-标题` 的命名格式：
- `XXX`：三位自增序号，全局唯一，便于引用和排序
- `YYYYMMDD`：文档创建日期
- `标题`：简洁描述文档主题
